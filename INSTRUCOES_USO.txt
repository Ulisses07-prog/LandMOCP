1. COMO INICIAR O SISTEMA LOCALMENTE
------------------------------------
Terminal 1 (Backend - API):
  cd backend
  uvicorn app.main:app --reload --port 8000

Terminal 2 (Frontend - Landing Page):
  cd frontend
  npm run dev

Acessos no navegador:
  Landing Page: http://localhost:3000
  Catalogo:     http://localhost:3000/catalogo
  Painel API:   http://localhost:8000/docs

3. BANNERS E OFERTAS NO TOPO
----------------------------
Para adicionar banners no carrossel de fotos do topo:
  - Basta colar a imagem em: frontend/public/images/banners/
  - O site atualiza automaticamente sem reiniciar.

Para sincronizar encartes verticais de promocoes:
  - Cole a foto em Promoções/ e rode:
    python sync_banners.py


4. COMO ATUALIZAR PRECOS E ESTOQUE VIA EXCEL
--------------------------------------------
Coloque a planilha oficial em: Produtos/tabela de produtos.xlsx
Execute no terminal:
  python scripts/sync_excel_catalog.py

O sistema recalcula automaticamente:
  - Estoque > 0: "Pronta Entrega"
  - Estoque == 0: "Sob Encomenda"


5. PUBLICAR ATUALIZACOES EM PRODUCAO (RENDER + VERCEL)
------------------------------------------------------
